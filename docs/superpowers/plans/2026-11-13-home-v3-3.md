# Home v3.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Act on the owner's third review of the home page. Give the header and boxes real inner padding. Recompose the hero as one big panel plus three small cards. Make photos fill their frames. Cut the radius scale to 24/16/12/8. Give the proof band the one big headline. Replace the jerky FAQ with a smooth Motion accordion and tune motion across the page. Close the trust gaps the audit found.

**Architecture:** Changes stay inside the `(home)` route group (`src/app/(home)/`, `src/components/home/`), plus:
- new tokens in `src/app/globals.css` and `src/lib/motion.ts`
- two small pure helpers in `src/lib/` (tested)
- one new client component `src/components/ui/faq-accordion.tsx`
- opt-in props on shared components (`ProductImage`, `BasketLink`), so other pages render exactly as before.

**Tech Stack:** Next 16.4 App Router (Cache Components), React 19, Tailwind v4 tokens, `motion` 14.1.1 (`LazyMotion` + `domAnimation`, `strict`, so `m.*` only), Vitest (node env), Playwright for measured QA.

**Spec:** `docs/home-v3/V3.3-BRIEF.md`. Its rulings point into `docs/home-v3/audits/layout.md`, `motion.md` and `gaps.md`, which hold the exact class values per section. Executors read the brief and the audit section named in each task.

## Global Constraints

- Home page only: no visual change to any other route. Shared components change only through new optional props whose defaults keep today's output.
- Colours through role tokens only; `src/lib/design-tokens.test.ts` stays green. No gradients, no glass. Lucide icons only.
- Radius on the home page: blocks `rounded-2xl` (24px), cards `rounded-xl` (16px), product cards `rounded-lg` (12px), images inside cards and every button and input `rounded-md` (8px). `rounded-full` only on pills that carry information (stickers, price tags, chips, lane labels, ticker dots, icon discs). Never `rounded-3xl` / `rounded-4xl`.
- Type: the proof headline is the only `text-display` (weight 600). Hero stays `text-h1`. Jamaica and closing headlines are `text-h2`, section titles `text-title`, card titles `text-lead`. Prices use the new `text-price` (18px). Headings weight 600, body 400; no hand-set tracking.
- Money via `src/lib/format.ts` only (`USD$31.50`, `J$3,100`). Same-day copy stays "we aim to". No invented numbers.
- Motion: 150–400ms for every interaction; only the ticker and real loaders loop; everything honours `prefers-reduced-motion`; CLS stays 0.00.
- 44px minimum touch targets; visible focus; works at 375px with no horizontal scroll.
- Commit after each task; push only once `npm run check` is green (end of Task 10). Do not commit the stray `@types/*` pins in `package.json`/`package-lock.json` unless the owner says so.

## Review Focus

1. **JavaScript off or the bundle failing:** every section must still be visible (today, 29 reveal elements ship at `opacity:0`). Task 3 adds the noscript rule; Task 10 QA checks with JS disabled.
2. **Keyboard and screen-reader use of the new FAQ:** Tab reaches each question, Enter/Space toggle it, `aria-expanded` flips, and closed answers are `inert`. Task 4 tests the toggle helper; Task 10 QA presses keys.
3. **Every featured basket unavailable, or fewer than three available:** the section shows the available ones or hides; it never shows "Not available today". Task 2 tests it.
4. **Reduced motion:** no rise, parallax, ticker, settle or panel animation; the FAQ opens in one frame. Task 10 QA emulates `reduce`.
5. **Long names and 375px:** "Baby & Child", two-line product names and the 48px proof headline must not overflow or misalign rows. Task 7 reserves two lines (`h-[2lh]`); Task 10 checks tile heights and price baselines.
